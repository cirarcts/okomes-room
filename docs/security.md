# セキュリティ・公開情報の取り扱い

公開情報・秘密情報・外部コンテンツの安全性に関する方針を管理します。

## 前提

- このサイトは静的サイトで、サーバー処理・認証・データベースを持たない。**閲覧者に届くものはすべて公開情報**として扱う。
- GitHub Pages（無料プラン）で公開するためリポジトリも公開される。**コミットしたファイルと過去の履歴はすべて誰でも閲覧できる**。

## リポジトリに入れないもの

- APIキー、トークン、パスワードなどの認証情報（`.env` は `.gitignore` 済み）
- 本名・住所・連絡先など、公開を意図しない個人情報
- 非公開の下書きやメモ（「未公開」フラグを付けても、リポジトリ上では読める）
- 写真・スクリーンショットに写り込んだ個人情報や、画像のExif位置情報
- 計測データ・ログに含まれるアカウントID、ローカルのファイルパスなど

誤ってコミットした場合は、ファイルを消すだけでは履歴に残る。認証情報は**ただちに無効化・再発行**したうえで、履歴からの削除を検討する。

## ビルド成果物

- `public/` と `src/` 配下のファイルは、参照のされ方によって `dist/` に出力される。公開前に `dist/` の中身を確認する。
- クライアントに渡す環境変数（`PUBLIC_` 接頭辞）に秘密情報を入れない。
- 使用している秘密の環境変数は `YOUTUBE_API_KEY` のみ。ビルド時のコンテンツローダーでだけ参照し、GitHub Secretsで管理する。APIキーはYouTube Data API v3のみに制限する（[deployment.md](deployment.md#github-secrets)）。ビルド後に `dist/` にキーが含まれていないことを確認する。
- YouTube API Dataは30日を超えて保存できないため、取得結果をリポジトリにコミットしない（[video-shelf.md](video-shelf.md)）。

## コンテンツの安全性

- コンテンツは管理者自身がリポジトリ経由で追加するもののみで、閲覧者からの入力は受け付けない。
- 外部から取得したデータ（計測ログ、エクスポートしたJSONなど）は、Zodスキーマで検証してから表示に使う。
- `set:html` や `dangerouslySetInnerHTML` で未検証の文字列をHTMLとして挿入しない。
- 外部リンクを新しいタブで開く場合は `rel="noopener noreferrer"` を付ける。

## 外部コンテンツ・埋め込み

- 動画などの埋め込み（YouTube など）は、提供元が公式に用意する埋め込み方法を使い、必要最小限の権限（`allow` / `sandbox`）に絞る。
- 動画の棚では、YouTubeのプライバシー強化モード（`youtube-nocookie.com`）を使い、再生ボタンが押されるまでプレイヤーを読み込まない。サムネイルは `i.ytimg.com` から読み込むため、閲覧時にGoogleへの通信が発生する。プレイヤーの識別に `Referer` が必要なため、`Referrer-Policy` で抑制しない（[video-shelf.md](video-shelf.md)）。
- 外部のスクリプト・フォント・CDNを追加する場合は、必要性と閲覧者のプライバシーへの影響（第三者への通信発生）を確認する。
- ゲーム画面、音源、機材の画像、フォント、有料素材などは、**権利者の利用規約・ライセンス・公開条件を確認してから**掲載する。

## 依存パッケージ

- 追加・更新時に `npm audit` を確認する。既知の事項は [development.md](development.md) に記載。
- 提供元やメンテナンス状況が不明なパッケージを安易に追加しない。
