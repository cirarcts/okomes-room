# デザイン

デザインコンセプト・配色・共通UIルールを管理します。
コンセプトの全文や各エリアのテーマは [idea.md](idea.md)（3〜7章）にあり、ここでは**実装が従うべき決定事項と現在の状態**をまとめます。

## コンセプト

**「夜の秘密基地のような、落ち着いた少し近未来的なおへや」**

優先順位は次のとおり。全体を派手なサイバーパンク調にはしない。

1. ダーク・落ち着いた秘密基地（基本）
2. ナチュラルで柔らかい雰囲気（親しみやすさ）
3. ポップ・デジタル・近未来的な表現（アクセント）

## デザイントークン

色は [src/styles/global.css](../src/styles/global.css) の `@theme` で定義し、Tailwindのユーティリティ（`bg-base`、`text-muted` など）として使う。
**現在の値は暫定**で、デザイン試作を通して確定する。色を直接コードに書かず、必ずトークン経由で指定する。

| トークン          | 用途                 | 暫定値    | 利用例        |
| ----------------- | -------------------- | --------- | ------------- |
| `--color-base`    | メイン背景           | `#0D1521` | `bg-base`     |
| `--color-surface` | カード・パネル       | `#182432` | `bg-surface`  |
| `--color-subtle`  | 補助背景             | `#111C29` | `bg-subtle`   |
| `--color-fg`      | メイン文字           | `#EAF0F5` | `text-fg`     |
| `--color-muted`   | 補助文字             | `#9EAAB7` | `text-muted`  |
| `--color-accent`  | デジタル系アクセント | `#72D4D0` | `text-accent` |
| `--color-warm`    | 暖色アクセント       | `#E9B77D` | `text-warm`   |

- アクセントカラーは多用せず、操作対象や重要な情報の識別に使う。
- シアン・ブルーグリーンは近未来感、アンバーは室内照明の温かみを表す。

## 共通UIルール

各展示室は独自デザインを採用してよいが、次は全ページで共通に守る。

- サイトの基本ナビゲーションと、トップページへ戻る操作
- スマートフォンを含むレスポンシブ対応
- 文字の可読性と十分なコントラスト
- キーボード操作とフォーカス表示（`:focus-visible` の共通スタイルを `global.css` で定義済み）
- 動きを減らす設定（`prefers-reduced-motion`）の尊重（`global.css` で一括対応済み）
- エラーや読み込み状態の表示
- 基本的な余白・レイアウトルール

アニメーションは控えめを基本とし、操作を妨げるものは避ける（ホバー時の明度変化、軽い浮き上がり、フェード、パネル展開など）。

## 共通ヘッダー

全ページの上部に固定表示する（[SiteHeader.astro](../src/components/SiteHeader.astro)）。

- 左にサイト名（トップページへ戻るリンク）を置く。各エリアでは右に共通ナビゲーションを置き、トップページでは本文の棚に入口を集約する。
- 日本語版のナビゲーションは日本語の表示名と等幅の英字補助ラベルを組み合わせ、英語版は英語の表示名を使う。
- 右上のJP／ENで同じページの言語を切り替える。現在の言語は枠と `aria-current` で示す。
- 現在いるエリアはアクセントカラーで示し、`aria-current="page"` を付ける。配下のページでもエリアを現在地として扱う。
- 各エリアの幅768px未満ではメニューボタンに切り替わり、ヘッダー直下にパネルとして開く。Escapeキーまたは外側の操作で閉じる。
- 操作対象の高さは44px以上を確保する。
- キーボード利用者向けに、ページ先頭に「本文へスキップ」リンクを置く（フォーカス時のみ表示）。
- JavaScriptが無効な環境では、メニューを常時表示にして操作できるようにする。

サイト名は現在テキスト表示で、ロゴ確定後に差し替える。

## トップページ「夜の棚」

[トップページ](../src/pages/index.astro)では、薄いシアンのグリッドを背景に、サイト名と3つの入口を収めた棚を配置する。棚の上端にはアンバーの間接照明を入れ、展示室の入口だけ右端に光が漏れる表現を加える。

- 幅768px以上ではサイト名と棚を左右に並べ、それより狭い画面では棚をサイト名の下に置く。
- 各入口はアイコン付きのリンクとし、選択中の言語で表示する。日本語版では英字の補助ラベルも付ける。共通ヘッダーと同じ項目定義を使い、JavaScriptが無効な環境でも各エリアへ移動できる。

### 光の演出

- グリッドの一部を淡いシアンの光が約22秒かけて横切り、棚の上端のアンバー照明は約13秒周期で明るさがゆっくり変化する。
- 入口にポインターを重ねるか、タッチするか、キーボードでフォーカスすると、その周囲のグリッドが約1秒だけ明るくなる。リンクの操作や遷移はそのまま行える。
- OSで「動きを減らす」が有効な場合やJavaScriptが無効な場合は静止表示になる。

## 展示室

[展示室](../src/pages/exhibits/index.astro)には、各展示への入口をパネルとして並べる。準備中の展示は一覧に状態を表示し、展示ページから一覧へ戻れるようにする。最初の展示は [Kemper Rig Viewer](../src/pages/exhibits/kemper/index.astro)。

[動画の棚](../src/pages/exhibits/video-shelf/index.astro)は、上部の再生ステージと動画カードの一覧で構成する。ステージはシアンの淡い光で縁取った16:9の画面で、幅の広い画面では最大幅を抑えて一覧が見えるようにする。カードはサムネイル・タイトル（2行まで）・公開元チャンネル・公開日を表示し、選択中のカードは枠をアクセント色にする。YouTubeが提供元であることと利用規約へのリンクをページ下部に示す。

Kemper Rig Viewerの一覧では、Rig名・アンプ名・概要を確認し、名前やエフェクト名などで絞り込める。一覧カードは高さを揃え、概要は2行を超えると「…」で省略する。概要の全文は個別ページで読める。個別ページは暗いパネルと緑の表示を使い、信号の順序を示す。AmplifierとCabinetは初期表示で開き、エフェクトは閉じて表示する。各パネルは個別に開閉でき、「すべて開く」「すべて閉じる」でまとめて操作できる。エフェクトの状態はLED風のマーカーと文字で示す。

Kemper Rig Viewerの一覧と個別ページは、実機の要素を取り入れた専用の背景（[KemperStage](../src/components/kemper/KemperStage.astro)）を持つ。ノブを囲むLEDリングを大きな光の輪として背景に置き、個別ページのパネルは実機のアーチ状の上辺に合わせて上側の角を大きく丸める。製品写真は権利上使用せず、CSSだけで描画する。スマートフォンでは本文の可読性を優先してリングの光量を抑える。

個別ページのRig名は、実機のバックライト付き液晶に合わせて、淡い緑の画面に暗い文字で表示する。信号の流れと設定パネルは、Stompsを暖色、Stack（Amplifier・Cabinet）を緑、Effectsをシアンで色分けし、上辺の線・見出し・設定値の色を揃える。色だけに頼らず、区分名は常に文字でも示す。シグナルチェーンと詳細パネルでは、ONのエフェクトを同じカテゴリ色のLEDで示す。Wahはオレンジ、Distortion・Booster・Shaperは赤、Equalizerは黄、Compressor・Noise Gateは青寄りのシアン、Chorus・Tremoloは青、Phaser・Flangerは紫、Pitch Shifterは青みのあるグレー、Delay・Reverbは緑、Pitch Delayは薄緑、Effect Loopは薄ピンクとする。

Amplifierの上段はProfiling Headの前面に合わせ、Gain、Bass、Middle、Treble、Presence、Rig Volumeの順で並べる。各ノブのLEDリングは実機に合わせて15灯で表示する。GainはKemper Genericまたは同じ値域を使う架空Rigで無単位の0〜10、EQの4項目は−5〜+5をノブで表示する。Rig Volumeは−96 dB（画面では−∞）を左端、0 dBを中央、+12 dBを右端とし、Gainと同じく左端から現在位置までLEDを点灯させる。中間値の位置は0 dBを境に、それぞれの値域で線形に補間する。Amp Volume（−12〜+12 dB）はAmplifierの数値一覧に表示する。「ノブ表示」の切り替えでは図だけを表示・非表示にし、値と単位は常に表示する。Gainの参照元は [Kemperスタッフによる説明](https://forum.kemper-amps.com/forum/thread/67274-having-some-issues-with-gain-levels/)。

「信号の流れ」では、スロット記号とLEDでエフェクトの位置と状態を示す。StackにはAMPとCABを並べる。機材名・エフェクト名は読み上げと詳細パネルで確認できる。スロットを選ぶと、該当する設定を開き、見出しにフォーカスを移す。見出しが画面外にある場合は、アニメーションを使わずにスクロールする。選んだスロットとパネルに、区分の色と枠線で選択状態を示す。ほかのパネルの開閉状態は維持し、選択中のパネルを閉じるか一括操作を行うと選択を解除する。JavaScriptが無効な場合も、ページ内リンクで該当パネルへ移動し、見出しから開閉できる。

ONは点灯、OFFは消灯、状態未取得は破線のLEDと文字で示す。名前が未設定のスロットは破線の枠と文字で示す。エフェクトのパラメータは数値・文字・単位をそのまま読める一覧にする。
